# خطة معايرة وتوحيد ألوان جميع الخرائط الثمانية والمفاتيح اللونية

تهدف هذه الخطة إلى مطابقة الألوان الظاهرة على كوكب الأرض في جميع الخرائط الثمانية مع المفاتيح اللونية السفلية بنسبة 100% وفق المعايير الرسمية لوكالة ناسا (`NASA GIBS v1.3`) ونماذج التضاريس والرياح الحية، مع معالجة اختفاء أو تشوه الطبقات وإعادة تصميم المفتاح اللوني ليصبح واضحاً بالكامل دون أي قصّ للنصوص.

---

## مراجعة القرارات المؤكدة (User Review & Critical Decisions)

> [!IMPORTANT] تم اعتماد الاختيارات التالية بناءً على إجاباتك:

- **توحيد الألوان مع خرائط ناسا الرسمية**: الإبقاء على طبقات الأقمار الصناعية الحية من ناسا (`NASA GIBS`) مع تعديل المفاتيح اللونية والتدرجات السفلية وتفسيراتها لتطابق بالضبط لوحات الألوان الرسمية الصادرة عن ناسا لكل منتج علمي (`MODIS NDVI`, `MODIS LST`, `SMAP Soil Moisture`, `GPM IMERG Precipitation`, `MODIS Cloud Fraction`).
- **معالجة البحار والمناطق الجافة**: إبقاء البحار والمحيطات بلونها الطبيعي وإظهار المناطق النشطة بشفافية متوازنة (عن طريق إزالة خلفية السماء الصافية/القيم الصفرية غير الفعالة في الطبقات التي تحتوي خلفيات معتمة، وعزل البحار عند اللزوم).
- **تصميم المفتاح اللوني السفلي**: تحويله إلى قائمة عمودية كاملة وواضحة بدون أي قصّ للنص العربي أو الإنجليزي، مع تمييز وإبراز الصف اللوني المطابق لقيمة النقطة المحددة حالياً على الخريطة.

---

## 1. نظرة عامة والسبب الجذري لاختلاف الألوان

أظهر الفحص الفني الدقيق للمنظومة الحالية أربعة أسباب حقيقية لاختلاف الألوان أو توقف ظهور بعض الخرائط:

1. **اختلاف تدرج ناسا الفعلي عن المفتاح القديم**:
   - طبقة الأمطار من ناسا (`IMERG_Precipitation_Rate`) تستخدم فعلياً تدرجاً يبدأ من **الأخضر الداكن والليموني** للأمطار الخفيفة والمتوسطة إلى **الأصفر فالبرتقالي والأحمر الداكن** للعواصف الغزيرة، بينما كان المفتاح السفلي يعرض تدرجاً أزرق/بنفسجياً؛ مما أدى لظهور ألوان خضراء فوق أفريقيا لا تطابق المفتاح.
   - الأمر نفسه ينطبق على طبقات الغطاء النباتي (`MODIS_NDVI`: بيج/بني للصحراء ثم أخضر فاتح إلى داكن)، وحرارة السطح (`MODIS_LST`: بنفسجي/أزرق للتجمد ثم أخضر نعناعي فأصفر وبرتقالي وأحمر للحرارة القصوى)، ورطوبة التربة (`SMAP`: برتقالي/أصفر للجفاف ثم أخضر فتركواز فأزرق وكحلي للتشبع)، والسحب والطقس (`MODIS_Cloud_Fraction`: أزرق فأخضر فأصفر فأحمر للسحب الكثيفة).
2. **فشل تحميل طبقة الغطاء النباتي (`404`)**: استخدام تاريخ ثابت (`2024-10-16`) تسبب في خطأ `404` مع مركب الـ 8 أيام لـ `MODIS_Terra_NDVI_8Day`، والحل هو استخدام مسار `default` القياسي الذي يعيد آخر صورة متاحة من ناسا بنجاح دائم (`200 OK`).
3. **خلفية السحب المعتمة (`MODIS Cloud Fraction`)**: تلوّن السماء الصافية (`0%–14%`) بالأرجواني والكحلي فوق القارات والبحار، ويلزم ترشيح هذه الخلفية الصفرية لتصبح شفافة مع الحفاظ على زرقة البحار.
4. **اختلال نطاقات الارتفاعات في المظلّل الرسومي 3D**: المظلّل الحالي يوزع التدرج خطياً بين `-80m` و`4200m`، مما أزاح ألوان السهول والهضاب (`50m–1000m`) عن نطاقاتها الدقيقة المذكورة في المفتاح اللوني للارتفاعات.

## 2. تجربة المستخدم والتصميم البصري (UX & Visual Design)

- **قائمة المفتاح اللوني العمودية الكاملة**:
  - عرض كل مستوى في سطر مستقل واضح (`مربع اللون الصافي` + `المدى الرقمي الدقيق بخط أحادي ثابت العرض tabular-nums` + `التصنيف والدلالة العلمية الكاملة` دون أي `truncate`).
  - **ربط حي بنقطة التفتيش (`Active Stop Highlight`)**: عند النقر على أي موقع على الكوكب (أو تحريك المؤشر/الزونة)، يُبرز المفتاح اللوني تلقائياً الصف المطابق لقراءة هذه النقطة بحدود مضيئة وعلامة «النقطة الحالية»، كما يظهر نفس اللون في بطاقة وزر «بيانات النقطة».
  - تصحيح اتجاه شريط التدرج اللوني (`gradientCss`) في الواجهة العربية (`RTL`) والواجهة الإنجليزية (`LTR`) ليتطابق طرفا الشريط بصرياً مع تسميتي الحد الأدنى والحد الأقصى بدقة.
- **مؤشر وضوح الخريطة الفوري**:
  - فور التبديل بين الخرائط الثمانية تظهر طبقة البيانات على الكوكب مباشرة بتدرج شفاف متوازن لا يطمس حدود الدول أو القمر الصناعي أو البحار، مع ظهور نقاط شبكية وأسهم واضحة في خريطة الرياح وعناقيد السحب الممطرة فوق مناطق الهطول النشطة.

## 3. القرارات الهندسية والمعايرة العلمية (Layer-by-Layer Calibration)

- **1. خريطة التنبؤ بالأمطار (`IMERG_Precipitation_Rate`)**:
  - تحديث رابط الطبقة إلى `default/default` لضمان أحدث رصد حي، وضبط المفتاح اللوني على لوحة ألوان GPM IMERG الرسمية (`#00764e` رذاذ `0.1–0.3 mm/hr`، `#68cb00` خفيف `0.3–1.0 mm/hr`، `#f7d900` متوسط `1.0–3.5 mm/hr`، `#ff5f25` غزير `3.5–9.0 mm/hr`، `#f30000` عاصف `> 9.0 mm/hr`) مع إبقاء المناطق الجافة (`< 0.1 mm/hr`) شفافة تماماً.
- **2. خريطة الغطاء النباتي (`MODIS_Terra_NDVI_8Day`)**:
  - إصلاح الرابط إلى `default/default` لحل خطأ `404`، ومطابقة المفتاح الثيماتي لألوان `MODIS_NDVI` الرسمية (`#dfcec2` جرداء `0.0–0.15`، `#b09b8a` تربة خفيفة `0.15–0.28`، `#bfde77` إنبات مبكر `0.28–0.42`، `#6eaa01` محصول نشط `0.42–0.65`، `#056400` غطاء كثيف `> 0.65`)، مع الإبقاء على ألوان مؤشرات الحقل التفصيلية للزونة كما هي دون كسر معايير الزونة الداخلية.
- **3. خريطة الحرارة (`MODIS_Terra_Land_Surface_Temp_Day`)**:
  - مطابقة المفتاح اللوني لألوان `MODIS LST` الرسمية المحوّلة من كلفن إلى مئوي (`< 0°C`: `#006bff` تجمد، `0–15°C`: `#24ffab` بارد، `15–28°C`: `#afff00` معتدل، `28–40°C`: `#ffd600` دافئ، `40–52°C`: `#ff6a00` حار، `> 52°C`: `#ff0100` إجهاد حراري شديد) مع بقاء البحار شفافة.
- **4. خريطتا رطوبة التربة والجفاف (`SMAP L4 Root-Zone Soil Moisture`)**:
  - مطابقة المفتاح اللوني لألوان SMAP الرسمية (`0–10%`: `#ffa200` جفاف حرج، `10–20%`: `#fff800` رطوبة منخفضة، `20–30%`: `#53a900` متوسطة، `30–40%`: `#00ca95` سعة حقلية مثالية، `> 40%`: `#008eff / #0000d4` تشبع مائي عالٍ).
- **5. خريطة الطقس والسحب (`MODIS_Terra_Cloud_Fraction_Day`)**:
  - إضافة مرشح شفافية فوري على مستوى البلاطة (`Canvas Pixel Masking`) يحوّل قيم السماء الصافية المعتمة (`0–14%`: `#660077`, `#000264`) ومسطحات البحار الصافية إلى شفافية كاملة، مع مطابقة المفتاح اللوني لألوان السحب الرسمية (`20–40%`: `#0003ff` سحب متفرقة، `40–60%`: `#055000` غطاء جزئي، `60–80%`: `#ffff01` غائم، `80–100%`: `#ff0005` سحب ركامية كثيفة).
- **6. خريطة ارتفاعات الأرض 3D (`Terrain3D + Shader`)**:
  - استبدال التوزيع الخطي داخل المظلّل بدالة استيفاء متدرجة مرتبطة مباشرة بحدود الارتفاعات الدقيقة (`0m, 50m, 200m, 500m, 1000m, 2000m, 3500m`) لكل من اللوحة العلمية واللوحة الطوبوغرافية التقليدية بحيث يطابق كل متر على الكوكب لونه في المفتاح اللوني 100%.
- **7. خريطة الرياح (`Live Open-Meteo Wind Field`)**:
  - إضافة طبقة حقل لوني حية شفافة متزامنة مع أسهم الاتجاه باستخدام ألوان المفتاح اللوني الخمسة لسرعة الرياح (`<12`, `12–18`, `18–24`, `24–32`, `>32 km/h`) مع عزل البحار للحفاظ على وضوح الكوكب.

## 4. المعمارية وتدفق البيانات (Architecture & Data Flow)

```
┌──────────────────────────────────────────────────────────────────────┐
│               Single Source of Truth: Layer Color Specs              │
│  NASA GIBS XML Stops (NDVI / LST / SMAP / IMERG / Cloud)             │
│  + Terrain3D Piecewise Elevation Stops + Open-Meteo Wind Stops       │
└───────────────────┬──────────────────────────────┬───────────────────┘
                    │                              │
        ┌───────────▼───────────┐      ┌───────────▼───────────┐
        │   Cesium 3D Renderer  │      │ Bottom Vertical Legend│
        │  - GIBS default tiles │      │ - Full non-clipped    │
        │  - Clear-sky & ocean  │      │   rows + RTL gradient │
        │    alpha masking      │      │ - Highlights active   │
        │  - Exact piecewise    │      │   inspected point row │
        │    3D height shader   │      │ - Synced Point Data   │
        │  - Wind speed field   │      │   badge color         │
        └───────────────────────┘      └───────────────────────┘
```

### تفاعل الحالة والتحديث الفوري
- اختيار أي خريطة من القائمة المنسدلة يُحدّث فوراً:
  1. طبقة البلاط أو المظلّل أو حقل الرياح داخل مشهد `Cesium`.
  2. مصفوفة التوقفات اللونية وتدرج الشريط والمعادلة العلمية في المفتاح اللوني السفلي.
  3. تمييز الصف اللوني المطابق لقراءة النقطة المحددة حالياً في نافذة المفتاح وزر «بيانات النقطة».
- الحفاظ على سلامة واجهات المحرك الزراعي الداخلي (`SPECTRAL_SCIENTIFIC_SPECS` و`getSpectralColor` واختبارات الزونات الـ 14) بدون كسر أي اختبار قائم، مع إضافة اختبارات جديدة للتحقق من مطابقة ألوان الخرائط الثمانية مع ألوان ناسا الرسمية ومفتاحها.
