# GeoAgri Pro 🌱🛰️
**Smart Agricultural & Geospatial Analytics Platform**  
*Developed by Team Geomatrix*

---

## 🌟 Overview
**GeoAgri Pro** is an advanced agricultural intelligence and satellite monitoring web platform designed to empower farmers, agronomists, and environmental decision-makers. By combining interactive 3D geospatial mapping (Cesium), real-time satellite spectral analysis (NDVI, NDRE, NDWI), weather forecasting, and Gemini AI-driven crop advisory, GeoAgri Pro provides actionable insights for precision agriculture.

---

## ✨ Key Features
- **🌍 Interactive 3D Geospatial Globe**: High-precision satellite layers, elevation modeling, and parcel boundary digitization.
- **🛰️ Satellite Vegetation Indices**: Real-time NDVI, NDRE, and NDWI indices for crop health, nitrogen levels, and moisture monitoring.
- **🤖 GeoAgri AI Advisor**: Multimodal Gemini AI assistant offering instant diagnosis, irrigation schedules, and pest control recommendations.
- **🌦️ Smart Weather & Alerts**: Microclimate forecasting, frost/drought early warning systems, and rainfall monitoring.
- **📊 Presentation & Project Deck**: Includes the official team presentation (`Geomatrix_GeoAgri_Pro_Presentation.pptx`).

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- npm or yarn

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/yasserelzanaty2-cloud/geoagri-pro.git
   cd geoagri-pro
   ```

2. Install dependencies:
   ```bash
   npm install --legacy-peer-deps
   ```

3. Set up environment variables:
   Create a `.env` or `.env.local` file and add your Google Gemini API key:
   ```env
   GEMINI_API_KEY=your_gemini_api_key_here
   ```

4. Run the development server:
   ```bash
   npm run dev
   ```

5. Open your browser and navigate to `http://localhost:3000`.
